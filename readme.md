# SmartWorkout API

Серверная часть фитнес-приложения SmartWorkout. Пользователь выбирает упражнения из каталога, собирает из них программы тренировок, добавляет чужие программы в избранное, проводит тренировки по программам и смотрит историю результатов.

Сервер написан на Python без веб-фреймворков: HTTP-сервер и маршрутизатор построены на стандартной библиотеке, данные хранятся в MongoDB.

## Описание эндпоинтов

Все эндпоинты RESTful-сервера описаны в спецификации OpenAPI 3.0: запросы, параметры, схемы и примеры ответов, коды ошибок.

**[Открыть описание API в Swagger Editor](https://editor.swagger.io/?url=https://gist.githubusercontent.com/MSNZT/bf7e4f4f69d8aba805ff4af982e9141d/raw/)**

Файл спецификации хранится в GitHub Gist: <https://gist.githubusercontent.com/MSNZT/bf7e4f4f69d8aba805ff4af982e9141d/raw/>. В ссылке нет хэша ревизии, поэтому после правок она не меняется и всегда отдаёт последнюю версию. Если ссылка на редактор не открылась, зайдите на [editor.swagger.io](https://editor.swagger.io/), выберите File → Import URL и вставьте ссылку на файл.

Почему не SwaggerHub: он и похожие сервисы бесплатно дают только пробный период. После него описание остаётся доступно только для чтения и больше не обновляется, поэтому спецификация хранится в Gist, а открывается в бесплатном Swagger Editor.

Ресурсы API:

- `/auth` — регистрация, вход, обновление токена и выход;
- `/exercises` — каталог упражнений, менять его может только администратор;
- `/programs`, `/me/programs` — программы тренировок: публичные и свои;
- `/me/favorites` — избранные программы;
- `/sessions`, `/me/sessions` — тренировки по программам и их история.

Ход тренировки (подходы, отдых, переход к следующему упражнению) ведёт клиентское приложение. Сервер сохраняет снимок программы при старте (`POST /sessions`) и итог тренировки при завершении (`POST /sessions/{session_id}/finish`).

## Запуск

```bash
cp .env.example .env              # настройки MongoDB и секрет для токенов
pip install -r requirements.txt
make start                        # MongoDB в Docker и сервер на http://localhost:8000
make start-ui                     # то же и веб-интерфейс базы DbGate на http://localhost:3000
make create-admin                 # администратор для правки каталога, нужна запущенная MongoDB
pytest                            # тесты, нужна запущенная MongoDB (make db-up)
```
